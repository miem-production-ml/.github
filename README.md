# Основы технологии производства и машинного обучения

Материалы проектного семинара МИЭМ НИУ ВШЭ, осень 2026 года.

Курс охватывает постановку задач машинного обучения, разведочный анализ данных, подготовку признаков, обучение с учителем и без учителя, временные ряды и основы нейронных сетей.
