# Основы технологии производства и машинного обучения

Материалы проектного семинара МИЭМ НИУ ВШЭ, осень 2026 года.

Курс охватывает постановку задач машинного обучения, разведочный анализ данных, подготовку признаков, обучение с учителем и без учителя, временные ряды и основы нейронных сетей.

## Преподаватели

- [Максим Грошев](https://miem.hse.ru/imsit/news/1118500895.html) — разработчик звуковых технологий VK Видео; ведёт введение в машинное обучение и занятия по нейронным сетям.
- [Даниил Ситдиков](mailto:d.sitdikov@vkteam.ru) — программист-исследователь VK Tech, работает с LLM и NLP; ведёт EDA, подготовку признаков и временные ряды.
- [Артём Петров](https://habr.com/ru/companies/vk/articles/900762/) — разработчик RAG-сервисов и AI-ассистентов VK; ведёт обучение с учителем и без учителя.
